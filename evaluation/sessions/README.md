# Usability sessions — participant records

Three formative, moderated think-aloud sessions against the dashboard, using the five-task script in `../eyetracking_tasks.pdf`. 
Each `P0x` session holds one anonymized record (participant ID only).

**Eye-tracking was not collected.** It was planned, but WebGazer would not write the gaze CSV on the test device 
(the *Download CSV* action produced an empty file), so the sessions were run as **oral / self-report + observational**:
participants answered each task question aloud while the facilitator recorded the answer, task success, time, and observed
 difficulty, followed by SUS and three open debrief questions. There is no gaze / AOI / heat-map data. See `../findings_summary.md` 
 for method, limitations, and the cited guidelines.

| Tester | Background | SUS | Headline finding |
|--------|------------|----:|------------------|
| `P01/` | Clinician | 82.5 | The CI bands are confusing (mean ± 95% CI vanishes when multiple cohorts are overlaid) |
| `P02/` | Clinical researcher | 70.0 | Clearing the cohort list one box at a time is tedious, wants a "Deselect all" button |
| `P03/` | Data analyst | 75.0 | Clicking a PCA point does nothing, wants the RID linked from PCA to Tab E |

Each testers's `P0x_session.md` is the session record (oral task answers vs expected, observed difficulty, SUS ratings, verbatim debrief).
