# Post-session debrief

After the five tasks, before the participant leaves, conduct a short
debrief in two parts: the System Usability Scale questionnaire (about
3 minutes) and three open questions (about 5 minutes). Record verbatim
quotes where possible.

---

## Part A — System Usability Scale (Brooke, 1996)

Read each item out loud and ask the participant to rate from
**1 = strongly disagree** to **5 = strongly agree**. Record the
integer rating only.

| #  | Statement | Rating (1–5) |
|----|-----------|--------------|
| 1  | I think that I would like to use this dashboard frequently. | |
| 2  | I found the dashboard unnecessarily complex. | |
| 3  | I thought the dashboard was easy to use. | |
| 4  | I think I would need the support of a technical person to be able to use this dashboard. | |
| 5  | I found the various functions in this dashboard were well integrated. | |
| 6  | I thought there was too much inconsistency in this dashboard. | |
| 7  | I would imagine that most people would learn to use this dashboard very quickly. | |
| 8  | I found the dashboard very cumbersome to use. | |
| 9  | I felt very confident using the dashboard. | |
| 10 | I needed to learn a lot of things before I could get going with this dashboard. | |

### Scoring

For odd-numbered items (1, 3, 5, 7, 9), subtract 1 from the rating.
For even-numbered items (2, 4, 6, 8, 10), subtract the rating from 5.
Sum the ten transformed scores and multiply by 2.5. The result is the
**SUS score** (0 – 100). A score above 68 is conventionally
considered above average.

---

## Part B — Open questions

Encourage think-aloud answers; do not lead.

### Q1 — Most confusing
> "Looking back across the five tasks, which moment or which screen
> was the most confusing for you, and what would have helped?"

### Q2 — Most useful
> "Was there any view or any feature that you found particularly
> useful — something you would want to keep if we removed everything
> else?"

### Q3 — Routine use
> "Imagine using this dashboard once a week as part of a clinical
> research routine. What is the single thing you would most want to
> change, add, or remove?"

---

## Closure

Thank the participant. Confirm that their Canswers are saved with their
participant ID and that no other identifying information is stored.
